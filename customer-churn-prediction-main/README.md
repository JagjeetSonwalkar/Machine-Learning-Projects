# Customer Churn Prediction

A Machine Learning project that predicts whether a telecom customer is likely to leave a service provider (churn) using a **Random Forest Classifier**.

This project uses the [Telco Customer Churn Dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn) and follows the complete Machine Learning workflow, including Exploratory Data Analysis (EDA), data preprocessing, model training, evaluation, and customer churn prediction.

## Features

- **Exploratory Data Analysis (EDA):** Analyzes data summaries, feature distributions, box plots, and correlation heatmaps.
- **Data Cleaning:** Performs data cleaning and generates a cleaned dataset.
- **Data Preprocessing:** Uses median imputation and feature scaling for numerical features, along with most-frequent imputation and one-hot encoding for categorical features.
- **Model Training:** Builds a Random Forest Classifier using a Scikit-learn Pipeline that combines preprocessing and model training.
- **Model Evaluation:** Evaluates model performance using accuracy, macro precision, macro recall, macro F1-score, classification reports, and confusion matrices.
- **Customer Prediction:** Provides an interactive command-line interface (CLI) to enter customer details and predict churn probability.

## Installation and Setup

### 1. Clone the Repository

```bash

```

```bash

```


### 4. Activate the Virtual Environment

**Windows:**



## Dataset

This project uses the [Telco Customer Churn Dataset](https://www.kaggle.com/datasets/blastchar/telco-customer-churn).

Download the dataset from Kaggle and place the CSV file in the following location:

```text
data/raw/WA_Fn-UseC_-Telco-Customer-Churn.csv
```

## How to Run the Project

Run the following scripts in the specified order from the `src/` directory.

### 1. Exploratory Data Analysis and Data Cleaning

```bash
python EDA.py
```

Explores the dataset, performs data cleaning, and generates the cleaned CSV file.

### 2. Model Training

```bash
python train.py
```

Trains the Random Forest Classifier, evaluates its performance, and saves the trained model.

### 3. Customer Churn Prediction

```bash
python predict.py
```

Starts an interactive CLI that collects customer information and predicts the probability of churn.

## Model Results

The Random Forest Classifier was evaluated on both training and testing datasets.

### Performance Comparison

| Evaluation Metric | Training | Testing |
|---|---:|---:|
| Accuracy | 82.77% | 78.35% |
| Macro Precision | 78.83% | 73.86% |
| Macro Recall | 84.92% | 78.52% |
| Macro F1-score | 80.32% | 75.03% |

### Key Observations

- The model achieved **82.77% training accuracy**.
- The model achieved **78.35% testing accuracy**.
- The testing macro F1-score is **75.03%**.
- The difference between training and testing performance indicates a generalization gap.
- Further model tuning and experimentation may help improve performance on unseen data.

*Note: These results are based on the evaluation metrics generated by the training script. Macro-averaged metrics are reported; class-specific metrics and ROC-AUC are not included in the current results.*
